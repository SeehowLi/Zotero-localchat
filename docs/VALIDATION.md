# 0.4.4 验证记录

日期：2026-09-19。测试使用独立 Zotero 配置及合成文件，没有发布真实账号或会话数据。

## 0.4.4 模型与强度同步

- 旧链路一次强度切换 HTTP 请求实测 3,385 ms；新链路三次分别为 29 / 25 / 38 ms，均读取 App 当前组件确认的真实档位。
- 新链路模型读取 HTTP 请求 5 ms；“最新 → GPT-5.5 → 最新”分别为 63 / 54 ms。上述为本机、当前 App 版本、已有连接的少量测试，不是跨设备延迟保证。
- 直接使用 App 原生选择回调，省去菜单开合及完整列表重读。回调后仍检查实际选中项；确认超时不会通过备用菜单重复执行。旧版组件缺少适配信息时才走原菜单路径。
- 模型使用侧栏内的菜单；缺少选中项的异常响应会保留上次确认的名称并标记未同步，不再把模型文字清空。
- 外观参考本机官方 App 的模型控件：紧凑胶囊按钮、较大的当前档位标签、粗滑条及白色滑块。

## 前端增量渲染与拖动回归

- 在真实 Chromium 页面中用原生鼠标按下、移动、释放拖动滑块：拖动期间保持非整数位置预览且不发送设置请求，释放后仅提交一次整数档位。
- 故意挂起后台设置响应：控件保持可拖动；旧响应不会把滑块拉回旧位置；所有请求串行，下一次仅提交最终选择。
- 三次快速滚轮输入只产生一次设置请求；后台拒绝设置时标记“未同步”并阻止误用旧设置发送，重连确认后恢复。
- 80 条历史消息下，同一帧内 100 次增量更新只绘制一次；历史 DOM 节点、文字选中内容和上翻位置保持不变。
- 320×360 侧栏与 160% 字号下，输入控件未超出视口；Ctrl＋滚轮、附件和发送流程保留回归覆盖。

这些是功能及调度验证，不代表任何机器上固定的帧率。

## 真实 App 与 Zotero

环境：Windows x64，Node.js 24.15.0，Zotero 10.0.3-beta.2，ChatGPT Windows App 26.915.4065。

- 打开空白聊天时没有上传或提交消息。
- 专用 App 页面隐藏后仍能发送并接收增量正式回答。
- 空白聊天逐行数字测试：提交约 417 ms，首段文字约 6,087 ms，4 次正式答案更新，总计约 8,565 ms。
- 同一对话追加合成文本文件，正确返回文件里的关键词 `OLIVINE` 和数字 `42`；完成后本机暂存副本不存在。
- 模型菜单读取到当前账号的真实可选模型；强度读取为“即时 / 中 / 高 / 极高 / Pro”，实际切换到“中”和“Pro”成功；“最新 → GPT-5.5 → 最新”经选中项核对成功。
- 升级独立 Zotero 中的插件后，从侧栏向已关联论文聊天提交“样本数加 4”；原测试 PDF 有 37 个样本，正确返回 `41`。前台仍是 Zotero，App 中转窗口处于隐藏状态。
- 修复阅读器工具栏拖动区域后，从收起状态点击 Local Chat 可直接展开侧栏。
- 外部 Origin 和缺失令牌的请求均返回 HTTP 403。
- 旧论文会话关联迁移后仍能定位；后续问题继续使用已经上传的 PDF。

以上是单机、指定版本和少量合成输入的功能验证，不是服务性能保证。首次建立或恢复后台窗口时仍可能短暂显示 App 新窗口；正常提问复用隐藏页面。其他 App 版本、其他语言界面、其他文件格式尚未逐一验证。
