# 同名论文恢复与跨设备续聊

适用于 0.4.12 及后续版本。

- 本机已有聊天 ID 关联时，始终恢复该聊天，不按名称改绑。
- 新设备首次打开论文时，在所选 ChatGPT 项目中查找同名聊天，匹配成功后保存云端聊天 ID。
- 标题比较忽略首尾和重复空白，支持插件原有的 160 字标题截断；不做模糊匹配。重复标题或列表未加载完成时不自动新建。
- 恢复已有聊天时沿用云端上下文，不重复上传 PDF。如旧聊天没有论文附件，可手动追加。
- 在 Zotero 继续提问会写入原云端聊天。另一台设备使用同一账号、同一 ChatGPT 项目，重新打开“论文对话”或点击“重连”后读取 App 已同步的历史。同步依赖 App 联网和云端加载；不是两台 Zotero 面板之间的实时广播。
- “新聊天”仍创建独立空白聊天，不匹配论文历史；“论文对话”仍返回论文关联的原聊天。
- 为避免串会话，不要同时在两台设备向同一聊天发送尚未完成的问题。

## 另一台 Windows 电脑升级

1. 等正在生成的回答结束，在旧包目录运行 Stop-LocalChat.cmd。
2. 把这个完整包解压到固定目录，运行 Start-LocalChat.cmd，更新本地服务路径。
3. 在 Zotero 插件管理器中安装包内的 0.4.12 XPI，保持插件与完整包版本一致。
4. 从 ChatGPT - Local Chat 快捷方式启动 App，在 Zotero 选择原 Paper 项目，重开论文对话。

无需复制 papers.json、账号凭据或论文库；现有本地关联优先保留。

0.4.12 同时修复后台窗口选择、初始化等待和窗口识别重试。
